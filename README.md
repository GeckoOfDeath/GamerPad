# GamerPad
GamerPad is a keyboard design that would allow you to quick chat in games without having to use time consuming text strings.

I worked around 20 hours on the project (missed time on lapis LoL). Even though i had to take a big break i think it came out well. Small ajustments as well as a QWK Firmware pass will be needed once i have the mother board. It will type say "/ hello" on its own so you can avoid all the random "enter" and "/" while gaming! I hope you enjoy!
